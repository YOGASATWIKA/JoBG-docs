# Glosarium

Daftar istilah agar semua dokumen memakai kata yang sama.

| Istilah                       | Arti                                                                                                           | Contoh                                                            |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| **JoBG**                      | Nama produk ini: portal lowongan kerja & magang untuk pencari kerja pemula                                     |                                                                   |
| **Pencari kerja pemula**      | Siapa pun yang belum pernah bekerja setelah lulus: mahasiswa tingkat akhir, pencari magang, dan fresh graduate |                                                                   |
| **Mahasiswa tingkat akhir**   | Pelajar/mahasiswa yang akan lulus dan mencari kerja atau magang                                                | Mahasiswa S1 semester 8                                           |
| **Pencari magang**            | Pencari pengalaman kerja pertama lewat program magang                                                          | Siswa SMK yang mencari PKL, mahasiswa D3                          |
| **Fresh graduate**            | Sudah lulus, masih mencari kerja, dan belum pernah bekerja setelah lulus (tanpa batas tahun lulus)             | Lulusan S1 Akuntansi 2025 yang belum bekerja                      |
| **Jenjang pendidikan**        | Tingkat pendidikan terakhir: SMA/SMK, D3/D4, S1, S2                                                            |                                                                   |
| **Perekrut / HR** | Orang dari perusahaan yang memakai dashboard admin JoBG: membuat lowongan, menilai, memutuskan, dan mem-blacklist | HR staf di perusahaan retail |
| **Dashboard admin** | Halaman kerja HR di JoBG | |
| **Perusahaan**                | Organisasi tempat perekrut bekerja; bisa dari sektor apa pun                                                   |                                                                   |
| **Sektor**                    | Bidang usaha perusahaan                                                                                        | Perbankan, retail, manufaktur, teknologi                          |
| **Lowongan**                  | Posisi yang dibuka perusahaan; jenisnya **kerja** atau **magang**                                              | "Staf Admin Keuangan", "Magang Marketing"                         |
| **Lamaran**                   | Pengajuan pencari kerja pemula ke sebuah lowongan                                                              |                                                                   |
| **Profil**                    | Data diri pencari kerja: jurusan, kemampuan, proyek, magang, organisasi, minat                                 |                                                                   |
| **Potensi**                   | Penilaian kemampuan pencari kerja pemula dari profil, bukan dari riwayat kerja                                 |                                                                   |
| **Kecocokan**                 | Seberapa sesuai profil pencari kerja dengan sebuah lowongan, beserta alasannya                                 |                                                                   |
| **Asisten AI**                | Fitur di website untuk bertanya dengan bahasa sehari-hari                                                      |                                                                   |
| **Data contoh (dummy)**       | Data fiktif yang dipakai untuk demo, bukan data orang asli                                                     |                                                                   |
| **Kriteria penilaian**        | Syarat tertulis sebuah lowongan, dibagi **wajib** dan **nilai tambah**, ditentukan sebelum melihat pelamar     | Wajib: jurusan akuntansi. Nilai tambah: pernah magang             |
| **Bukti**                     | Bagian dari profil kandidat yang menunjukkan sebuah kriteria terpenuhi                                         | "Magang 3 bulan di KAP X" → bukti untuk kriteria pengalaman audit |
| **Penilaian tanpa identitas** | Menilai kandidat dengan nama, foto, dan kampus disembunyikan untuk mengurangi bias                             |                                                                   |
| **Lihat sekali lagi**         | Tanda dari AI bahwa sebuah keputusan HR tampak tidak sesuai dengan kriteria                                    | Kandidat sesuai semua kriteria wajib tapi dihentikan              |
| **Blacklist** | Pemblokiran kandidat oleh HR karena perilaku (data palsu, spam, semena-mena); berlaku di perusahaan itu; **wajib disertai alasan** yang bisa dilihat kandidat | |
| **Banding** | Pengajuan kandidat agar blacklist dicabut, setelah memenuhi alasan blacklist; diputuskan HR | Mengganti data palsu dengan bukti asli |
| **Klaim** | Data yang diisi kandidat tanpa bukti pendukung | "Mahir Excel" tanpa sertifikat atau contoh kerja |
| **Terbukti** | Data yang didukung dokumen, link, atau hasil tugas | IPK dengan transkrip terlampir |
| **Tugas singkat** | Pertanyaan atau tugas kecil sesuai lowongan untuk melihat kemampuan langsung | Studi kasus 10 menit |
| **Alur rekrutmen** | Urutan tahap sebuah lowongan; bagian tengahnya disusun HR | Seleksi berkas → Tes → Interview → Penawaran |
| **Tahap** | Satu langkah dalam alur rekrutmen, dengan data yang diminta, kriteria, dan keputusan | "Interview User" |
| **Jenis tahap** | Kategori tahap yang disediakan JoBG: seleksi berkas, permintaan dokumen, tes/tugas, interview, penawaran | |
| **Template alur** | Alur rekrutmen yang disimpan HR untuk dipakai ulang | |
| **Rawan klaim** | Data yang sering dikosongkan sekaligus sering dilebih-lebihkan; wajib dibuktikan | Pengalaman, kemampuan, skill |
| **Master user** | Satu-satunya pengelola JoBG; akses penuh; menambahkan perusahaan & membuat akun HR | |
